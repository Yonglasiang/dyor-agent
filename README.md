# DYOR Agent

### Don't Trust the AI. Use AI to DYOR.

DYOR Agent is a beginner-first crypto research AI agent built for Binance Agent OS.

Instead of telling users what to buy or sell, it helps beginners understand what they are researching, identify potential risks, recognize missing information, and build their own research checklist.

## The Problem

"Do Your Own Research" is common advice in crypto, but beginners are rarely shown how to actually do it.

New users may struggle to understand:

- Token utility
- Tokenomics
- Liquidity
- Holder concentration
- Market volatility
- Contract risks
- Project documentation
- What information is missing

DYOR Agent turns DYOR from a vague warning into a structured learning process.

## How It Works

User asks about a crypto asset
        ↓
DYOR Agent
        ↓
Collect relevant information
        ↓
Explain it in beginner-friendly language
        ↓
Identify risks and unknowns
        ↓
Create a personalized DYOR checklist
        ↓
User makes their own informed decision

## Core Principle

> Don't trust the AI blindly.
> Use the AI to learn how to verify information yourself.

The agent does not provide guaranteed predictions or tell users that an asset is safe or profitable.

Instead, it clearly separates:

🟢 What we know

🟡 What needs verification

🔴 Potential risk signals

⚪ What we cannot verify

## Safety

DYOR Agent is designed as a research and education tool.

It does not:

- Guarantee profits
- Claim an asset is safe
- Replace independent research
- Make decisions for the user
- Require access to the user's personal trading funds

The agent should clearly communicate uncertainty and encourage users to verify important information independently.
