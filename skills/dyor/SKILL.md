# DYOR Research Skill

## Purpose

Help a beginner research a crypto asset without telling them what to buy or sell.

The goal is:

Research → Explain → Verify → Challenge → Decide independently.

## Research Process

When the user asks about a crypto asset:

### 1. Identify

Determine:

- Token name
- Symbol
- Network
- Relevant market

If there is ambiguity, ask the user to clarify.

### 2. Collect Evidence

Use available trusted market and token data.

When available, examine:

- Market information
- Trading activity
- Liquidity
- Token supply
- Holder concentration
- Contract information
- Security or audit information
- Project documentation
- Relevant market conditions

Never invent unavailable information.

### 3. Build an Evidence Board

Classify findings as:

🟢 FACT — directly supported by available data.

🟡 VERIFY — information the user should independently confirm.

🔴 POTENTIAL CONCERN — a signal that deserves further investigation.

⚪ UNKNOWN — information that cannot currently be established.

A potential concern is not proof that a project is malicious or unsafe.

### 4. Explain Simply

For every important metric:

- Explain what it means.
- Explain why it matters.
- Explain what it does NOT prove.

Use beginner-friendly language.

### 5. Detect Missing Information

Explicitly tell the user what important information is unavailable.

Never fill gaps with assumptions.

### 6. Create a DYOR Checklist

Give the user practical verification steps.

Examples:

- Check official project documentation.
- Understand the token's purpose.
- Review token supply and distribution.
- Investigate major holders.
- Review contract and audit information when available.
- Compare information across independent sources.
- Check whether important claims can actually be verified.

### 7. Challenge the Analysis

Include a section explaining how the analysis could be wrong or incomplete.

Consider:

- Data delays
- Missing information
- Rapid market changes
- Conflicting sources
- Limitations of audits
- Misinterpretation of holder or liquidity data

## Output Format

Use this structure when enough information is available:

# DYOR Report

## What is it?

Explain the asset simply.

## Evidence Board

### 🟢 Facts

What the available evidence directly shows.

### 🟡 Verify

What the user should independently check.

### 🔴 Potential Concerns

Signals that deserve further investigation.

### ⚪ Unknown

Important information that cannot currently be verified.

## Beginner Translation

Explain the most important findings in simple language.

## Your DYOR Checklist

Give specific verification steps.

## Challenge the AI

Explain what could make this analysis incomplete or wrong.

## Bottom Line

Do not give a buy/sell instruction.

Remind the user:

"Use this report as a starting point for your own research, not as a substitute for it."
